## 3. 能力晋升的证据门槛

unknown → observed：有对应真实样本；observed → verified：关键成功与失败场景有回放及实际路径证据，且明确账号、版本、限制；verified → enabled：经阶段批准。证据过期或协议变化可变 stale；安全或语义冲突可 quarantine。

UI 功能存在、README 声称、模型自述、论坛体验和旧仓库星数均不能单独满足 verified。一次样本也不足以推出所有账号、所有输入、所有时间都稳定。

## 4. 两项风险不由技术成功消除

**授权与条款**：官方个人服务条款中含程序化提取、反向工程及绕过限制等约束；适用账户、地区与服务协议需具体核对，本书不作合法性保证。[O3](../../research/prior-art-prb/sources.md#o3)

**服务存续与访问范围**：官方产品页说明其定位，并不构成长期可用或固定模型承诺。P0 应实际核对账号能否访问和服务现状；不能只因网页还存在就承诺上游持续可用。[O1](../../research/prior-art-prb/sources.md#o1)

## 5. 关闭未知项的格式

在对应实现 change 记录 Uxx、scope、版本、证据引用、覆盖与盲区、结论及 reviewer；来源原件留 Research Dossier 或受保护证据目录，模块只回填长期合同。若事实推翻本书设计，先改 owner 章节并让消费者对齐，不能在代码里偷偷绕过。
