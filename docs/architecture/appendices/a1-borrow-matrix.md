## 2. 成本与收益判断

优先实现的是**不做就无法信任结果**的机制：提交账、上下文隔离、结果完整性、单所有者和权限。它们直接解决重复请求、串数据与伪成功。

管理后台、多 provider、分布式扩容与 LLM 审计平台暂不带来首轮可验证收益，因此后置。工程量目前没有代码基线与协议证据，不给虚构 LOC／周数；阶段计划用依赖与验收门槛而非日历估算。
